## kim-tigerj — AI 관제·원격제어 완성·에이전트 근본 분석

**원격제어 WebRTC both-relay 완성과 권한 판정 배선 (OR-1703, OR-1892)**.
TURN-over-TCP 양방향 릴레이를 끝맺고 Chrome ICE tiebreaker 0을 받아들여 연결을 세웠으며, offer를 즉시 보내고 후보를 양방향으로 트리클했다. 매니저 토큰 전달·크레덴셜 403 차단·수락 대기/거부 화면을 붙이고, 거절을 세션 완전 종료로 처리해 옛 프레임이 새 세션을 끊지 못하게 했다.

**확산 예측·탐지 cron을 서비스로 통합 (OR-1680)**.
확산 예측과 탐지를 매시 도는 cron에서 process_aggregator 서비스로 합치고, prediction-detect를 매일 03:20 1회 실행과 logrotate로 등록했다. 실행 주기를 테스트 운영으로 매시 20분에 맞춰 돌렸다.

**정팀장 서버 관제와 AI 책장 구조 (OR-2126, OR-2092, OR-2123, OR-2192)**.
analyst2를 DGX·vLLM responses API로 옮기고, 점검 지침을 서가-책꽂이-블럭-책-목차-챕터 계층으로 다시 짜 모델이 한 번에 한 층씩 꺼내 점검하게 했다. 매니저에는 명령 걸린 시각·에이전트 응답 전문·검색 인용·선택 근거·결론 되돌림을 담은 서버 관제 위젯을 새로 만들었고, 결론을 확인한 명령과 서버 자료로만 내리도록 못 박았다.

**덤프 분석기와 커널 System 입출력 원인 규명 (OR-2242, OR-2239)**.
덤프 분석기 결과를 탭으로 나누고 심볼 없는 유발자를 버그체크 첫 인수로 짚었으며, MEMORY.DMP가 있어도 미니덤프가 선택되던 로직을 고쳤다. 커널(System, SUID 4)이 낸 입출력을 순위와 무관하게 늘 서버로 올리고, 프로그램이 일으킨 몫은 '대기'가 아니라 '지연'으로 표기하도록 에이전트·서버·매니저를 함께 고쳤다.

**주기 업무 리뷰 자동 발행 (OR-984)**.
주기 리뷰 자동화에 LLM 폴백 구조를 넣고, 실패 경보를 로그 문구가 아니라 종료코드 기준으로 바꿔 오탐을 없앴다. Slack 발송을 python 헬퍼로 돌려 한글이 깨지던 문제를 막았다.

## smahn9123 — 명령 정확화·데이터 모델 분리·패키징 체계

**복수 대상 명령과 동적 대상 게이트 해제 (OR-2026)**.
복수 대상·제외를 걸어도 명령이 켜지도록 동적 대상 게이트를 걷어냈다. 대상 칸이 '고정 대상'으로 떨어지던 것, 가상그룹 제거가 복수 포함에서 대상을 잘못 버리던 것을 집합 판정으로 바로잡았고, 유령 노드 탈락이 통계에 안 잡히던 것도 한 군데로 모았다. 분기 최대 작업으로 32커밋이 들어갔다.

**command 결과를 command_node로 분리 (OR-1849)**.
command.results 배열 쓰기를 걷어내 결과를 command_node로 옮기고, 고아 정리 스크립트를 배포 대상에 넣었다. 배열이 16MB를 넘겨 실패해도 command_node는 살아남음을 검증했다.

**빌드 버전과 lock 판정 체계 (OR-1428, OR-1468)**.
빌드 산출물을 배포 서버에 올리는 단계를 더하고 회차별 버전을 체계화했다. lock 판정이 same이면 이전 빌드가 남긴 .new를 지우고, 버전 점프 폭(PATCH/MINOR/MAJOR)을 표시하도록 했다.

**명령·결과 보존 기간과 TTL 삭제 부하 실측 (OR-2161, OR-2012)**.
명령과 결과가 언제까지 남는지 날짜로 보여 주고, 아직 도는 명령에 결과가 지워졌다고 말하지 않게 고쳤다. '몇 시간~며칠'로 과장돼 있던 TTL 삭제 부하와 백필 시간을 실서버 실측치로 확정했다.

**coturn 릴레이 보안 차단 (OR-1752)**.
coturn 릴레이가 서버 내부 서비스로 향하는 SSRF 경로를 막고, v4-mapped IPv6와 멀티캐스트 우회를 차단했다. 필터 주입을 템플릿 수렴 방식으로 바꿔 재발을 눌렀다.

## kimyh-orange — 전체 노드 부하 요약·릴리즈 노트·룰

**전체 노드 부하 요약 판정 카드 (OR-2250, OR-1675)**.
전체 노드 부하 요약을 차트·알약 대신 판정 한 줄과 지표 6칸으로 바꿨다. 7일 중앙값·MAD로 평소보다 높음을 가리는 배너를 넣고, 확인하기를 누르면 시간 요약이 열려 누가 부하를 올렸는지와 원인 프로그램을 쉬운 문장으로 짚게 했다. 1시간 보기와 하루·시간 요약도 함께 만들었다.

**노드 목록 차트·실행 횟수 정리 (OR-1517)**.
노드 목록의 실행 횟수 컬럼을 걷어내고, 좁은 화면 차트를 넓은 화면과 맞췄다. log 축 꼭대기를 데이터 최대에 맞춰 값이 43인데 축이 100까지 벌어지던 것을 고쳤다.

**COM·PC명 중복 룰 정비 (OR-2147, OR-2179)**.
COM 통신 룰의 요약 필드가 엉뚱한 값을 담던 것을 제공자 정보로 바로잡고 용어를 'COM 통신'으로 통일했다. PC명 중복 룰(RULE 91)은 접미사로 원인을 나누고 충돌 이름·상대 IP로 묶어, 같은 이름이 왜 겹쳤는지 가려 보게 했다.

**패키지 릴리즈 노트 운영 (OR-1730, OR-2214)**.
패키지 여러 회차의 릴리즈 노트를 작성해 홈페이지에 게시하고, 릴리즈 노트를 에이전트·서버·매니저 영역별로 구획했다. PDF 대신 인웹 상세로 바꾸고 릴리즈당 파일을 분리했다.

## wychoi-orangelabs — 에이전트 필터·종료 검증·소프트웨어 서버 이관

KillProcessInPath 함수 진입부에 경로 검증을 더해 잘못된 경로로 종료가 번지지 않게 했다. 분기 최대 작업으로 24커밋이 들어갔다.

**DNS·TCP 도메인/프로세스 필터 (OR-1844, OR-2000, OR-1949, OR-1934)**.
도메인 네임 필터 항목을 손보고 DNS 캐시 시점에 isFiltered 마지막 값을 우선하게 했으며, DNS 실패 이벤트를 걸러냈다. TCP 프로세스명 필터 항목을 더하고, 프로세스 귀속을 이벤트 PID 하나로 통일했으며, 영원히 0이던 disconnect 통계를 TCB 장부에서 분리해 바로잡았다.

**COM 플러그인 결함·누수 수정 (OR-2147)**.
dllhost COM 구성요소를 로드된 모듈로 정확히 짚고, ETW 소비가 멈춘 채 방치되던 결함과 누수를 고쳤다. 트리거 B를 걷어내고 표기와 로그를 정리했다.

**소프트웨어 관측 화면 서버 이관 (OR-1559, OR-1562, OR-1558, OR-1573)**.

**드라이버 코드사인 (OR-1034)**.
orange.sys 드라이버를 orange·MS 사인으로 서명하고 inf를 바로잡아 버전을 올렸다.

**영어 로컬라이징과 미사용 코드 대량 정리 (OR-2231, OR-2208, OR-2212)**.

## 분기 흐름 요약

이번 분기는 '만든 기능을 끝까지 밀어붙여 실전에 올린' 분기였다. 원격 화면 제어는 폐쇄망 TURN-over-TCP 양방향 릴레이와 권한 판정까지 끝맺어 제품에 들어갔고, 확산 예측·baseline 분석은 서비스·API로 정리돼 매니저 화면과 이어졌다. 명령 관리는 복수 대상 게이트 해제와 데이터 모델 분리로 정확해졌으며, 에이전트는 DNS·TCP 필터와 COM·종료 경로의 근본 결함을 걷어냈다. 프론트에서는 설정·GNB 재편과 미사용 코드 대량 정리로 신뢰성을 끌어올렸다. AI 관제(정팀장)는 책장 구조와 확인된 근거 기반 결론으로 한 축을 더 세웠다.
